# Simple-E-commerce
Kode ini merupakan projek kecil kami, yaitu sebuah E-commerce kecil. Disini kami membuat dengan beberapa fitur dengan pembeli dan penjual. Penjual dapat menambahkan barang yang ada di toko. Pembeli bisa mendapatkan diskon serta akan mendapatkan diskon tambahan jika memiliki kartu member.
